\section{Writing}
\label{sec:writing}

Text goes here. A citation looks like this~\cite{knuth1984}, and a
cross-reference to Section~\ref{sec:maths} looks like that.

LaTeX earns its keep once a document grows past a few pages. Because
sections, figures, tables, citations, and equations are all referred to by
label rather than by page or number, reorganizing a long report --
inserting a new section, reordering chapters, adding a reference in the
middle -- never requires manually renumbering anything that follows.
Content and formatting stay separate, so a thesis or a paper can be
restyled by changing a handful of preamble settings instead of touching
every page by hand. And because the source is plain text, it works well
under version control, diffs cleanly, and survives being merged and
reviewed the way code does -- all properties that matter more, not less,
as a document gets longer. In particular, since each sentence typically
sits on its own line, a Git diff shows exactly which sentences changed
instead of reflowing the whole paragraph into one indistinguishable
block. It also means several authors can draft different sections at once,
since Git's line-based merges resolve most simultaneous edits
automatically instead of requiring one person to hold the file locked.
